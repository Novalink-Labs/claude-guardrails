This is one design-language preview page for Khoj, a calm, trustworthy home-search product for families.

PASS if the page defines its colours as CSS custom properties with light and dark values; loads a deliberate font pairing (not only Inter, Roboto or the system font); shows a type specimen, the colour tokens with contrast ratios, and buttons or inputs in more than one state; and includes a realistic Khoj screen with real copy about homes, areas or prices (not placeholder text).
FAIL if any of those is missing, or the page uses purple-to-blue gradients, emojis as icons, or placeholder copy.
